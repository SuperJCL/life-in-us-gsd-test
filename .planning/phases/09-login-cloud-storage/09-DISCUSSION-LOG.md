## 打开时的等待和连不上

| Option | Description | Selected |

| 你来定 | 由 Claude 定 | |

**联网却连不上服务器时怎么做？**

| Option | Description | Selected |
|--------|-------------|----------|
| 给看上次的内容（只读），加“重试” (Recommended) | 能看不能改，状态栏写明连不上并给出重试，连上后自动放开；Phase 10 再升级成断网可记 | ✓ |

**对账超过约 3 秒怎么办？**

| Option | Description | Selected |
|--------|-------------|----------|
| 提示“网络较慢”，继续等到约 15 秒 (Recommended) | 3 秒后改提示，约 15 秒仍未完成才算连不上 | ✓ |

**服务器内容比本机新、页面换成新内容时要提示吗？**

| Option | Description | Selected |
|--------|-------------|----------|
| 不提示，直接换 (Recommended) | 正常情况，提示会变成每次打开都弹 | |

**Notes:** 写入 CONTEXT 时限定为“本机有缓存且内容确实不同”才提示，第一次在设备上登录不提示。

## 退出登录和登录过期

**点“退出登录”时，有修改还没保存到服务器上怎么办？**

| Option | Description | Selected |
|--------|-------------|----------|
| 先等保存完，存不上再问我 (Recommended) | 通常一秒内存好并退出；存不上时让你选再试一次或仍然退出 | |
| 弹确认框让我选 | 只要有没保存的修改就问一句，不自动等待保存 | ✓ |
| 直接退出 | 没保存的修改直接丢掉，不推荐 | |

**登录过期后再打开应用，这台设备上该账号的内容怎么处理？**

| Option | Description | Selected |
|--------|-------------|----------|
| 先留着，本人重新登录后接着用 (Recommended) | 回到登录页提示过期；同一账号重新登录照常对账；换账号登录先清掉前一个账号的内容 | |
| 一律清掉 | 最干净，但没传上去的修改会丢 | |
| 你来定 | 由 Claude 定 | ✓ |

**登录页要不要预填上次用的邮箱？**

| Option | Description | Selected |
|--------|-------------|----------|
| 只在登录过期时预填 (Recommended) | 过期时预填省事；主动退出后不记，共用设备时别人看不到登录邮箱 | |
| 一直记住上次的邮箱 | 最方便，退出后也预填 | ✓ |
| 从不记住 | 每次都重新输入 | |

**User's choice:** 弹确认框；登录过期交给 Claude；一直记住邮箱。
**Notes:** 写入 CONTEXT 时把“还有没下载的冲突留底”也纳入退出确认框的提醒范围（来自第三块的决定）。

## 冲突留底怎么提示和下载

**发生覆盖时怎么告诉你？**

| Option | Description | Selected |
|--------|-------------|----------|
| 弹提示，另留一个常驻入口 (Recommended) | 当下弹提示并带下载按钮；页面上另常驻“下载留底”入口 | ✓ |
| 只弹提示 | 提示消失后就没有入口了 | |
| 只留常驻入口 | 不弹提示，容易注意不到 | |

**这台设备上留几份被覆盖的版本？**

| Option | Description | Selected |
|--------|-------------|----------|
| 留最近 3 份 (Recommended) | 连续几次覆盖也不丢前一份，超过 3 份删最旧的 | |
| 只留最近 1 份 | 最省空间；连续两次覆盖时第一份会被替换 | ✓ |
| 你来定 | 由 Claude 按存储容量定 | |

**留底什么时候清掉？**

| Option | Description | Selected |
|--------|-------------|----------|
| 手动清，退出时一并清 (Recommended) | 直到点“丢弃留底”或被下一次覆盖替换；退出时提醒并清掉 | |
| 下载后自动删 | 下载一次就删；退出时同样提醒并清掉 | ✓ |
| 你来定 | 由 Claude 定 | |

**“下载后自动删”具体怎么删？**（提问时已说明：页面无法确认下载的文件是否真的存好了）

| Option | Description | Selected |
|--------|-------------|----------|
| 留到下次打开应用再删 (Recommended) | 这次打开期间还能再下一次，下次打开时自动删 | |
| 点下载就立刻删 | 最干净；如果这次下载没存好，留底就没了 | ✓ |

**User's choice:** 弹提示加常驻入口；只留 1 份；点下载立刻删。
**Notes:** 所有者在知情的情况下接受了“下载没存好就丢留底”的风险。

## Claude's Discretion

- 登录过期后的本机缓存：保留该账号的缓存（含未上传修改和留底），同一账号重新登录后照常对账；换另一个账号登录时先清掉前一个账号的数据，有未上传修改或留底时先提示。
- 连不上时是否在后台自动重试（至少要有手动重试）。
- 缓存键与对账表的实现、留底的存储位置、云端下载机制、两个标签页同时退出、登录页错误文案的区分。
