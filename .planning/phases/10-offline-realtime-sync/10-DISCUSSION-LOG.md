## 打开时连不上还能不能记

**问题 1：** 打开应用时连不上服务器、但本机有缓存，要不要允许继续记录？

| Option | Description | Selected |
|--------|-------------|----------|
| 放开，按离线处理 | 连不上也能记，联网后自动上传；缓存旧时会整份覆盖别的设备的修改，被覆盖的版本留底 | ✓ |
| 只在浏览器明确断网时放开 | 浏览器显示联网但连不上服务器时仍只读 | |
| 保持只读（第 9 阶段现状） | 最不容易覆盖别的设备，但连不上时一笔都记不了 | |

**问题 2：** 什么时候转入“离线也能记”？

| Option | Description | Selected |
|--------|-------------|----------|
| 明确断网立即转，否则等 15 秒 | 浏览器显示断网时直接离线可记；联网时仍按 3 秒“较慢”、15 秒转离线 | ✓ |
| 一律等 15 秒 | 飞行模式下打开也要等 15 秒 | |
| 缩短到约 5 秒就转 | 更快能记，但对账没做完就放开，覆盖风险变大 | |

**问题 3：** 离线记录后重新联网，遇到真冲突怎么办？

| Option | Description | Selected |
|--------|-------------|----------|
| 本机为准上传，服务器版留底 | 照第 9 阶段已定的规则，弹提示并可下载 | ✓ |
| 服务器为准，本机离线修改留底 | 手机久未打开时丢得少，离线记了一整天时丢得多 | |
| 停下来让我选 | 需要新增界面和文案 | |

**User's choice:** 三题都选了推荐项。

## 远端更新遇上正在写的内容

**问题 1：** 远端更新挂起时，在这台设备上保存了修改，另一台设备的那次修改怎么办？

| Option | Description | Selected |
|--------|-------------|----------|
| 先应用远端，再加上你这次的 | 只重做结束忙碌的那一个操作，两边都保留 | ✓ |
| 整份最后保存的为准 | 最简单，但前后脚记一笔时前一笔会从服务器上消失（留底可下载） | |

**问题 2：** 写草稿时点“现在更新”，草稿怎么处理？

| Option | Description | Selected |
|--------|-------------|----------|
| 保留草稿文字 | 草稿文字和类别照旧在 | ✓ |
| 丢弃草稿 | 最简单，但容易误点丢字 | |

**问题 3：** 编辑框里的记录在另一台设备上被删了，点“保存”怎么办？（只是文字被改过时，以本机这次保存为准。）

| Option | Description | Selected |
|--------|-------------|----------|
| 按你的修改加回这条记录 | 加回并提示曾被删除；不要再删一次即可 | ✓ |
| 不保存，提示已被删除 | 尊重另一台设备的删除，编辑框文字留着可复制 | |

**User's choice:** 三题都选了推荐项。

## 待上传数量怎么数

| Option | Description | Selected |
|--------|-------------|----------|
| 按改动过的条目去重 | 每条记录、任务、每周复盘、力量项、开始日期各算 1 项，改几次都算 1 项 | ✓ |
| 按操作次数 | 每次操作算 1 项，写复盘每停笔一次算 1 项；数字容易偏大 | |
| 和上次上传的版本逐项比较 | 最准，但要在本机多存一份整份文档，接近容量上限时存不下 | |

**User's choice:** 按改动过的条目去重。

## Claude's Discretion

- 用着用着断网、服务器出错或登录过期：照常能记；自动重试一直进行，间隔逐步拉长，最长 60 秒；“离线”和“保存失败、几秒后重试”分开显示；登录过期后点“重新登录”走第 9 阶段的登录页。
- WR-01（写入方 id 每个标签页一个、刷新不变）和 WR-02（保存超时、`saving` 复位）的修法。
- 重连时不重新加门控；上传等待期间到达的远端更新能重做就重做，否则整份覆盖加留底。
- 同一浏览器两个标签页同时离线的处理，或写进已知限制。
- 实时订阅的字段、`PB_CONNECT` 后的对账时机，交给阶段调研。
