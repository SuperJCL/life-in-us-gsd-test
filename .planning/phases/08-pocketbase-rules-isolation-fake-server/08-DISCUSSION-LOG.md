## 前提确认：数据库

所有者先问“这个 PocketBase 是干嘛用的”。Claude 解释：
- 它就是服务器上运行的后端程序，同时管数据库、登录和实时同步；
- Phase 8 在本机临时跑一份同版本的 PocketBase，只用来验证规则，不存真实数据。

所有者接着问：“我之前是想用数据库服务存数据的，你现在给我整成啥了呀”“为什么不用 postgres 这些的正规数据库服务呢”。Claude 说明：
- PocketBase 内部就是 SQLite 数据库；
- 用 PostgreSQL 还得另写登录、权限和实时同步的后端；
- 另外比较了托管 PostgreSQL、Supabase 和服务器内存、费用、国内访问几个方面。

| Option | Description | Selected |
|--------|-------------|----------|
| 继续用 PocketBase | 保持现方案，接着讨论 Phase 8 | ✓ |
| 换成 PostgreSQL | 先整理要改哪些阶段、多出哪些活、每月多少钱，再请所有者确认 | |

**User's choice:** 继续用 PocketBase。
