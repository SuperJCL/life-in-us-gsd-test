## 执行约束

- **隐私：** 页面、README 和 SUMMARY 里不写真实域名和 IP，链接一律写成 `https://<域名>/probe/`；域名由所有者私下发给测试的人。
- **写法（analog：06-PATTERNS.md § `tools/probe/page/index.html` 与 `probe.js`）：** 原生 HTML/JS，一个 IIFE，不往 window 挂东西（只读取 SDK 定义的全局 `PocketBase` 和 config.js 定义的 `window.PROBE_CONFIG`）；可选能力（wakeLock、Paint Timing）用 try/catch 包住；错误显示在页面状态行，不调用任何控制台输出接口；页面文字一律用 textContent 写入，不用任何 HTML 字符串拼接接口；中文界面。
- **D-17：** Task 2 批准之前不下载任何东西，也不运行 `npm view`、`npm pack` 这类会联网取包的命令；规划时已读到的 registry 元数据写在 Task 2 里。
- **下载的文件是不可信数据：** tarball 放进 `mktemp -d` 新建的空目录，解压到另一个新建的空目录，只取需要的两个文件；不在那些目录里运行任何解释器或构建工具。
- **不改应用文件，不加 npm 依赖，不跑 Playwright。**
- **提交：** 每个自动任务一次提交，说明结尾加你的运行时要求的 Co-Authored-By 署名行；经过 pre-commit 钩子；不推送。
