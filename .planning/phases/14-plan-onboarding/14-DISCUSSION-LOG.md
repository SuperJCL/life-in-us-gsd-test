## 挑完之后

| Option | Description | Selected |
|--------|-------------|----------|
| 进草稿，点保存才生效 (Recommended) | 和编辑计划页一致，可以顺手改，也可以放弃 | |
| 挑完直接保存 | 少点一步，马上在目标页看到 | ✓ |

**User's choice:** 挑完直接保存
**Notes:** Claude 对编辑页里的情况这样理解：编辑页本身是草稿，所以在编辑页里「从示例添加」时，勾选的项加进草稿，和其他修改一起保存，免得把别的未保存修改一起存掉。直接保存只用在空计划卡片上（14-CONTEXT D-07）。已在总结里告诉所有者。
