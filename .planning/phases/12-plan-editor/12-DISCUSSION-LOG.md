## 删除与归档

### 什么情况归档、什么情况直接删

| Option | Description | Selected |
|--------|-------------|----------|
| 有进度才归档 (Recommended) | 已完成或设了截止日期才归档，没有进度直接从草稿移除；组里有进度或自定义待办时删组也归档 | |
| 一律归档 | 不管有没有进度都归档；「已归档」区会堆很多没用过的项 | |
| 归档后也能彻底删除 | 有进度先归档；在「已归档」区可以再「彻底删除」，确认后连进度一起删，日历和时间线里的完成记录也消失 | ✓ |

**User's choice:** 归档后也能彻底删除

### 归档项在哪里出现

| Option | Description | Selected |
|--------|-------------|----------|
| 目标页隐藏，历史照常 (Recommended) | 目标页和本周计数都不再出现；日历和时间线的完成记录照常；归档任务不再显示截止提醒 | |
| 目标页变灰放最后 | 目标页底部一个可折叠的「已归档」分组，灰色只读；日历和时间线照常 | ✓ |
| 截止提醒也保留 | 同第一项，但日历上仍显示归档任务的截止提醒 | |

**User's choice:** 目标页变灰放最后

### 组归档时组里的自定义待办

| Option | Description | Selected |
|--------|-------------|----------|
| 跟着组一起归档 (Recommended) | 留在原组，一起变灰、一起恢复；彻底删除组时写明几条待办一起删；顺带修 WR-02 | ✓ |
| 移到「其他」组 | 挪到「其他」组继续显示；恢复组时不自动挪回 | |
| 先让我处理待办 | 组里还有未完成的自定义待办时不让归档 | |

**User's choice:** 跟着组一起归档

### 归档任务的截止提醒

| Option | Description | Selected |
|--------|-------------|----------|
| 不再显示 (Recommended) | 日历上不再提醒，CSV 也不带；截止日期仍在数据里，恢复后回来 | ✓ |
| 照常显示 | 归档只影响目标页，日历和 CSV 不变 | |

**User's choice:** 不再显示
**Notes:** 这一问是对上一题「日历和时间线照常」的澄清。力量项的归档显示随第二题定：在「已归档」区只读显示历史，因此没有单独提问。

## 两台设备同时改计划

### 编辑草稿时另一台设备保存了计划

| Option | Description | Selected |
|--------|-------------|----------|
| 弹框让我选 (Recommended) | 编辑时顶部提示；保存时三选一：用我的覆盖（留底可下载）/ 放弃我的修改用新版 / 回去继续改 | ✓ |
| 直接覆盖并留底 | 不问，最后保存为准，留底可下载 | |
| 放弃草稿、重新打开 | 别处保存后不让保存，提示基于新版重改 | |

**User's choice:** 弹框让我选

### 草稿里删掉的无进度任务刚在别处有了进度

| Option | Description | Selected |
|--------|-------------|----------|
| 自动改为归档 (Recommended) | 保存时复查，刚有进度的改为归档，保存后提示 | |
| 保存前先问我 | 列出这些项，让我选归档还是连进度一起删 | ✓ |
| 按草稿删掉 | 以草稿为准，另一台设备刚打的勾丢掉 | |

**User's choice:** 保存前先问我

### 草稿改到一半页面被刷新或被系统关掉

| Option | Description | Selected |
|--------|-------------|----------|
| 草稿存本机，回来时问 (Recommended) | 随改随存本机（不上传），再打开时问继续编辑还是丢弃；退出登录时删掉 | |
| 不保留 | 只在页面开着时保留，刷新或被关掉就没了；离开时尽量提示 | ✓ |

### 点保存时要不要先显示改动摘要

| Option | Description | Selected |
|--------|-------------|----------|
| 直接保存 (Recommended) | 点保存就生效，回到目标页并提示「计划已保存」 | ✓ |
