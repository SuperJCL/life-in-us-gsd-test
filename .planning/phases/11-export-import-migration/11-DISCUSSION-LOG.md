## 导入时替换哪些内容

**问题 1：** 导入新格式的备份（计划加记录）时，替换哪些内容？

| Option | Description | Selected |
|--------|-------------|----------|
| 计划和记录都替换 | 恢复成备份时的样子，确认框写明两者都替换 | ✓ |
| 只替换记录，计划不动 | 计划只在编辑计划页里改；记录里的任务进度可能对不上 | |
| 确认时让我选 | 确认框里两个勾选项；界面和用例更多 | |

**问题 2：** 导入原 Artifact 的旧备份（只有记录）时，计划怎么办？

| Option | Description | Selected |
|--------|-------------|----------|
| 只替换记录，当前计划不动 | 旧备份本来就没有计划 | ✓ |
| 计划也重置为示例计划 | 导入后的状态只由文件决定，但会冲掉已有的计划 | |

**问题 3：** 要不要接受只有计划的文件？

| Option | Description | Selected |
|--------|-------------|----------|
| 接受，只替换计划 | 记录不动；给 Phase 12 的“导入计划”铺路 | ✓ |
| 不接受 | 只认完整备份和旧备份 | |

**User's choice:** 三题都选了推荐项。

## 撤销导入

**问题 1：** 导入前的快照留多久、“撤销导入”入口放哪？

| Option | Description | Selected |
|--------|-------------|----------|
| 留到下次导入或退出登录 | 常驻入口放在导出按钮那一栏，刷新后仍在，只在导入的设备上 | ✓ |
| 本次打开期间可撤销 | 刷新或关掉页面就没了，不占本机存储 | |
| 只在导入后的提示里撤销 | 几秒后消失，最简单但容易错过 | |

**问题 2：** 导入后又记了新内容，这时点“撤销导入”怎么办？

| Option | Description | Selected |
|--------|-------------|----------|
| 恢复到导入前，先确认 | 有新修改时先弹确认框说明会一起撤掉 | ✓ |
| 有新修改后就不能撤销 | 避免误丢新修改，但导错了没法回退 | |

**User's choice:** 两题都选了推荐项。

## 你的旧数据怎么搬进新账号

**问题 1：** 个人计划和原 Artifact 的旧备份，用什么方式搬进新账号？

| Option | Description | Selected |
|--------|-------------|----------|
| 分两步导入 | 先导入计划文件再导入旧备份；脚本只碰种子 | |
| 本机脚本合成一个文件 | 所有者在本机运行脚本，把种子计划和旧备份合成一个新格式备份，一次导入；脚本要读真实备份 | ✓ |

**问题 2：** 导入旧备份时，有任务进度对不上当前计划怎么办？

| Option | Description | Selected |
|--------|-------------|----------|
| 摘要里醒目提示，仍可导入 | 按 Phase 7 规则丢弃，原文件还在，可以先导入计划再导一次 | ✓ |
| 有对不上的就拒绝导入 | 最不会丢，但计划有意改过时导不进来 | |
| 保留对不上的进度 | 推翻 Phase 7 的“丢弃孤儿进度”决定 | |

**问题 3：** 迁移流程的演练要不要所有者亲手做一遍？

| Option | Description | Selected |
|--------|-------------|----------|
| 自动演练加验收时试一次 | 用例在假服务器上跑完整流程，验收时在本机真实 Edge 里用合成文件走一遍 | ✓ |
| 只要自动演练 | 等 Phase 13 真迁移时才第一次亲手做 | |

**User's choice:** 第 1 题没有选推荐项，选了“本机脚本合成一个文件”；第 2、3 题选了推荐项。
**Notes:** 按项目约束，合成脚本由所有者本人在本机运行，Claude 只写脚本并用合成文件测试，不读真实备份（写进 CONTEXT D-06）。
