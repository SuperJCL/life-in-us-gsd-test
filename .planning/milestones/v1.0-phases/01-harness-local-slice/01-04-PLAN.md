## Phase Goal

**As a** 开发者, **I want to** 在项目目录运行 `npm test`，用本机 Edge 跑通一条本地模式的端到端用例, **so that** 网络拦截、固定时钟、页面错误和应用完整性这几道护栏从第一条用例起就自动生效，后续阶段依赖的运行时假设都已经用探针验证过。

（三个槽位都逐字取自 ROADMAP Phase 1 的 Goal。）

- 连续两次用交付配置运行，结果一致（ENV-04、D-04），隐私全量检查通过（D-09）；
- 两条只读的自动检查证明 UI 模式参数存在、show-report 来自项目内的 Playwright（D-01）；
- 最后一个 blocking-human 检查点：用户亲自运行 `npm run test:ui` 回放 IO-01，并用 `npx playwright show-report` 打开报告（D-01）。

产出：tests/README.md、playwright.config.ts 的 PW_JSON_REPORT 文件报告器，以及阶段末的人工验收结论。
</objective>
