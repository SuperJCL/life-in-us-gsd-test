## Phase Goal

**As a** 开发者, **I want to** 在项目目录运行 `npm test`，用本机 Edge 跑通一条本地模式的端到端用例, **so that** 网络拦截、固定时钟、页面错误和应用完整性这几道护栏从第一条用例起就自动生效，后续阶段依赖的运行时假设都已经用探针验证过。

（三个槽位都逐字取自 ROADMAP Phase 1 的 Goal，没有新增内容。ROADMAP 里的 Goal 还不是标准的用户故事格式；如果要改成标准格式，可以运行 `/gsd-mvp-phase 1`。）

<objective>
搭起 Walking Skeleton。目标是让下面这条链路从头到尾跑通一次：

`npm test` → Playwright 用系统 Edge → `tests/support/static-server.cjs` 在 127.0.0.1 提供页面 → 应用以本地模式运行 → 在本周视图记一笔 → 防抖保存到 localStorage → reload → 记录仍在。

这条链路从第一次运行起就受两个 auto fixture 保护：网络护栏 `guard` 和固定时钟 `frozenClock`。

目的：在最早的上下文里先证明整套架构可行（tracer-first），后面的计划在它上面扩展：Plan 02 做护栏自检，Plan 03 做 AppHarness 和探针，Plan 04 做文档、阶段收尾和人工验收。

产出：package.json、package-lock.json、playwright.config.ts、静态服务器、constants、strings、唯一的 test 出口、smoke spec，以及两个阻塞检查点（安装前确认包的合法性；Edge 无法驱动时停下询问）。
</objective>
